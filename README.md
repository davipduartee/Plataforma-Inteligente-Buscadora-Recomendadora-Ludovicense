# Plataforma-Inteligente-Buscadora-Recomendadora-Ludovicense
Projeto em grupo para a disciplina de design/Front end, propondo uma solução que ajuda consumidores de São Luís a decidir entre comprar local ou online, comparando preço, frete, prazo e confiabilidade via IA. Inclui ideia de negócio, fluxo do produto, wireframe das telas e landing page.
## Protótipo

Telas do fluxo de busca inteligente, na ordem de navegação do usuário:

1. `assets/01-tela-inicial-home.png` — Página inicial, com busca por texto, link ou imagem
2. `assets/02-busca-passo1-produto.png` — Passo 1: o que o usuário está procurando
3. `assets/03-busca-passo2-prazo.png` — Passo 2: prazo desejado para a compra
4. `assets/04-busca-passo3-orcamento.png` — Passo 3: faixa de orçamento
5. `assets/05-ia-analisando.png` — Tela de carregamento, IA comparando fornecedores
6. `assets/06-resultados-recomendacao.png` — Resultado com veredito da IA e ranking de opções
7. `assets/07-top-fornecedores.png` — Ranking geral de fornecedores ludovicenses
